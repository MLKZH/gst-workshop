# GST Мастерская

Приложение для учета клиентов, услуг, заказов, чеков и квитанций сервисной мастерской GST.

## Что умеет

- вход для трех пользователей: Азиз, Муслим, Дамир;
- отдельная база клиентов, услуг и заказов для каждого пользователя;
- телефон клиента можно оставить пустым;
- готовые клиенты: аппараты акима Талгарского района и аппарат районного маслихата;
- создание услуг для быстрого заполнения заказа;
- печать короткого чека и полной квитанции;
- публичная страница проверки ремонта по номеру заявки;
- условия GST в квитанции: гарантия, хранение, согласование ремонта;
- запуск локально и публикация на сервере.

## Локальный запуск

Нужен Node.js версии 18 или выше.

```bash
npm start
```

После запуска откройте:

```text
http://localhost:3000
```

Страница для клиентов:

```text
http://localhost:3000/track.html
```

После публикации отправляйте клиенту ссылку:

```text
https://ваш-сайт.onrender.com/track.html
```

## Настройки

Для репозитория используйте `.env.example` как пример переменных окружения.

На хостинге лучше задать свои значения:

- `GST_SECRET` - длинная случайная строка для защиты входа;
- `GST_AZIZ_PASSWORD` - пароль Азиза;
- `GST_MUSLIM_PASSWORD` - пароль Муслима;
- `GST_DAMIR_PASSWORD` - пароль Дамира;
- `DATA_DIR` - папка, где хранятся базы.

## Базы данных

Файлы базы создаются автоматически при первом входе:

- `data-aziz.json`
- `data-muslim.json`
- `data-damir.json`

Эти файлы не добавляются в репозиторий, потому что там будут реальные клиенты и заказы.

## Публикация

Инструкция для Render находится в файле:

`README_DEPLOY.md`

Важно: для настоящей работы мастерской подключите постоянный диск на хостинге, иначе данные могут пропасть после перезапуска бесплатного сервера.
