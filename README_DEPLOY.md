# GST: публикация в интернет

Приложение теперь можно запускать как сайт с общей базой данных.

## Локальный запуск

1. Откройте папку проекта:
   `C:\Users\Aliya\Documents\Codex\2026-05-22\new-chat`
2. Запустите:
   `npm start`
3. Откройте:
   `http://localhost:3000`

Пользователи по умолчанию:

- Азиз: `aziz123`
- Муслим: `muslim123`
- Дамир: `damir123`

У каждого пользователя отдельная база:

- `data-aziz.json`
- `data-muslim.json`
- `data-damir.json`

## Публикация на Render

1. Создайте новый Web Service на Render.
2. Загрузите этот проект через GitHub или вручную через репозиторий.
3. Укажите:
   - Build Command: пусто
   - Start Command: `npm start`
4. Добавьте переменные окружения:
   - `GST_AZIZ_PASSWORD` - пароль Азиза
   - `GST_MUSLIM_PASSWORD` - пароль Муслима
   - `GST_DAMIR_PASSWORD` - пароль Дамира
   - `GST_SECRET` - любая длинная случайная строка
   - `DATA_DIR` - папка для базы, например `/var/data`
5. Если нужен постоянный учет заказов, подключите Persistent Disk и укажите mount path `/var/data`.

После публикации Render даст ссылку вида:
`https://gst-workshop.onrender.com`

Страница для клиентов будет здесь:
`https://gst-workshop.onrender.com/track.html`

Клиент вводит номер заявки из квитанции, например `AZ-R-0001`, и видит текущий статус ремонта.

## Важно

Без постоянного диска данные на некоторых бесплатных хостингах могут сбрасываться после перезапуска сервера. Для мастерской лучше включить Persistent Disk или позже подключить полноценную базу данных.
